# Nova Client

Nova Client is a polished PvP-client-style Minecraft mod for 1.8.9. It features a ClickGUI with categories like Combat, Movement, Render, Player, World, HUD, and Misc. The mod includes performance optimizations such as particle reduction and configurable entity render distance. It is designed to be lightweight and efficient, ensuring smooth gameplay even on lower-end computers.

## Installation

1. Install Minecraft Forge for 1.8.9.
2. Place the NovaClient.jar file in your mods folder.
3. Launch Minecraft via Forge.

## Usage

1. Launch Minecraft with Forge.
2. Press Right Shift (RSHIFT) to open the ClickGUI.
3. Navigate through the categories to configure various settings.
4. Use the in-game settings to adjust performance optimizations as needed.
